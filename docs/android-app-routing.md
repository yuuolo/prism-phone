# Android 按应用分流与节点质量

Beta.6 已发布下列两项，当前 Beta.7 同时修正主页接管与 DNS 保护范围提示，完整发布结果见[发布说明](releases/android-0.2.0-beta.7.md)。既有规则、代理链、优选、广告拦截及升级方式保留。原七项高级目标的剩余范围见[路线](android-advanced.md)。

## 按应用控制 VPN 接管

在“设置 → 按应用分流”选择全部应用、仅所选应用经过 VPN，或所选应用绕过 VPN。可搜索当前用户可见的启动器应用，也可手动添加当前可见、已安装的应用包名。最多 256 个包名，切换模式保留原选择，修改需断开并重新连接。

进入 VPN 的应用继续遵循规则/全局/直连模式。绕过 VPN 的应用使用系统网络，其 DNS、流量及广告请求不进入 Prism 统计或拦截；不代表为应用指定不同节点。应用主动使用本机 HTTP/SOCKS5 代理时仍通过代理，系统“阻止无 VPN 连接”也可能阻断绕过应用。

实现使用 Android 的 [VpnService.Builder 应用列表](https://developer.android.com/reference/android/net/VpnService.Builder)，每个连接仅设置包含或排除其中一种列表。包含模式显式保留 Prism 自身，以便控制界面、DNS 与就绪检查使用同一 VPN。用户不能排除 Prism 或与 Prism 共用 UID 的包；其他共用 UID 应用一起生效，工作资料和其他用户受其自身系统 VPN 管理。

不申请 `QUERY_ALL_PACKAGES`，只声明启动器 Intent 的可见性查询。不可见的非启动器应用可能无法选择，不把不可见当作未安装的确定结论。保存和每次连接前均检查当前可见性/安装状态；活动列表中失效的包名阻止连接，不静默删除或扩大范围。可在“查看所选应用 / 移除失效包名”删除，或切回全部应用模式。包名列表保存在既有 Keystore 加密配置中，不创建明文应用清单或后台扫描。

旧配置缺少 `appRouting` 时保持原来全部应用接管，不批量重写原配置。新字段为 version 1、mode（all/include/exclude）、packages；包含列表不得为空，重复包名、未知字段、无效版本/包名均拒绝，保存比较加载时版本并拒绝运行中修改。全部应用模式保留未启用的原选择，不因失效选择阻止连接。

## 节点质量曲线

“设置 → 节点质量曲线”读取候选组现有 HTTPS 健康探测。每节点最多保留当前内核最近 10 个真实样本，包含采样时间与探测耗时。曲线横轴为时间、纵轴为耗时，失败用红叉且断开连线；失败不计入最小/平均/最大值，不画成 0 ms。显示“失败次数/探测次数”，不称为网络丢包率或带宽。

页面不发起任何探测，前台每 2 秒读取状态，暂停后停止读取；数据未变不重建视图，保留滚动与阅读位置。无探测、未启用候选组、VPN 未运行和读取失败均有明确状态。历史不落盘，网络重建或断开后清空；重建继承的已知可用性不生成历史样本或时间。初次探测只能显示已有点，不填充模拟曲线。曲线同时提供逐项文字供无障碍阅读。

## 软件验收

本地 Android 8 已验证独立应用 UID 的实际 SOCKS 响应：无 VPN 可达，全部接管且规则拒绝时不可达，排除该应用时可达，包含该应用时不可达，仅包含其他应用时可达，切回全部后再次不可达。另验证运行中/过期修改拒绝、失效包名不启动、原配置默认保持，以及界面截图。`routeprobe` 是独立可调试验收应用，只访问固定模拟器端点，不进入正式 APK、不生成 Release 变体。

候选组验收读取真实失效/成功节点的历史及时间，并在网络重建后确认历史清空；质量模型拒绝成功 0 ms、失败伪造数值和超额历史。已检查空状态与真实样本截图。Beta.6 与 Beta.7 完整 CI 均通过 Android 8 和 Android 17/16 KiB 各 23 项回归、各自独立 180 秒 Doze，并完成原签名 Beta.5→Beta.6→Beta.7 连续覆盖。实际应用名单跨补丁升级保留且主页范围正确；结果在发布说明中记录，模拟器不替代真机验收。
