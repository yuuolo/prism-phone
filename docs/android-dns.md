# Android 高级 DNS

Beta.8 候选实现了加密上游、域名策略、fallback 和 hosts；IPv6 尚未开放。入口在“设置 → DNS 高级设置”，修改须先断开，下次连接生效。可停用自定义设置，或填入默认值后保存；停用时仍校验所保存字段，默认值保留原代理加密 DNS 和独立节点引导地址。数据进入既有 Keystore 加密配置，不增加后台更新或测速任务。

普通上游 1–3 个，节点引导 1–2 个，策略最多 16 条且每条 1–2 个上游，fallback 最多 3 个，fallback 域名/结果网段各最多 32 条，hosts 最多 128 条，配置合计最多 64 KiB。支持 HTTPS DoH 与 TLS DoT；禁止明文、跳过证书检查、账号、查询参数、片段及 IPv6 上游。普通上游可使用域名，节点引导必须是加密公网 IPv4 字面地址，不引入额外明文 bootstrap。

普通 DNS、策略和 fallback 强制附加当前代理的 proxy-only 标记；只有节点端点引导可使用独立直连加密上游。直连/全局模式不改变这个 DNS 隐私边界。策略按顺序首次命中，模式为精确域名、`+.`（本域及子域）、`.`（仅子域）和 `*.`（一层子域），不支持本批未经数据校验的 geosite DNS 模式。策略命中后不改用普通/fallback 或节点引导 DNS。

fallback 是并发询问后选择回答，不是出错后切直连：主回答正常时保留主回答；空结果、指定 IPv4 网段可采用候补；指定域名仅询问候补。候补失败仍可能采用主结果。没有默认 GeoIP 过滤。多上游增加查询量，只在发生解析时使用，不安排额外后台请求。

静态 hosts 在客户端仍返回 fake-IP，保留域名规则、广告计数和拒绝路径；规则匹配后对拨号目标应用 IPv4，保留原连接元数据与实际出口归属。支持 TCP/UDP；节点端点解析也可使用 hosts，其局域网覆盖加入 Android 17 权限预检。hosts 不接受内部 VPN/虚拟地址、IPv6、未指定、组播或广播地址。绕过 VPN 的应用与远端代理自身其他 DNS 行为不受此配置控制。

手机共享快照新增 `prism-fake-ip-hosts`，默认关闭；原有未启用该项的 hosts 行为保持不变。它使 fake-IP 模式的客户端请求先保留域名，真实地址解析仍返回 hosts 绑定，再在 Tunnel 的 TCP/UDP 出站拨号前应用覆盖。该改动仅在手机仓库，未修改桌面仓库，同步上游时必须保留域名拒绝、真实转发、旧行为与网络恢复回归。

本机代理防回环同时检查 hosts 覆盖后的节点地址。实际回归先复现原检查未识别域名映射、同端口监听被接受，再验证修复后在绑定前明确拒绝；不发起自连流量。停用自定义 DNS 后不再应用该覆盖。

软件验收包含配置逃逸拒绝、代理-only 与独立引导的生成配置、真实 SOCKS 下 DoH/DoT 拒绝自签名证书、真实 hosts TCP/UDP、域名拒绝和旧开关兼容。Android 验证实际加密解析、主解析不可用时分域优先、fallback 可用与匹配策略不偷偷回退、fake-IP hosts 到真实代理载荷、拒绝规则和流量归属、网络重建保留当前 fake-IP 及 hosts、旧修订/运行中保存拒绝和界面截图。跨 VPN 会话不复用旧 fake-IP，重建在同一会话内核对映射保留；不得将这两类行为混为一谈。完整 CI 与原签名覆盖结果见发布说明，不以模拟器替代真机验收。
