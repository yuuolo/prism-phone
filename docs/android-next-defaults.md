# Beta.4 启动、默认策略与路由改进

本页记录 Beta.3 发布后的开发，已随 Beta.4 交付；不改变已发布 Beta.2/Beta.3 的二进制或版本号。

## 分发与兼容

主发布继续使用 `yuuolo/prism-phone` 的 Android Release；Beta.4 APK 已在该仓库。发布脚本同时保留 `yuuolo/prism` 镜像及旧仓库专用更新清单，不删除旧资产、不把旧客户端不接受的地址替换进旧通道。新旧通道使用相同原签名 APK、版本、大小与摘要，各自指向各自仓库的下载地址；桌面 latest 不参与。Beta.4 使用 versionCode 5，后续版本继续递增。

## 首次数据准备

正常首次启动自动调用生产下载器，先下载 GeoIP 和 GeoSite，核对可信发布元数据中的大小、SHA-256、来源与重定向，再生成地区/地区分类目录。广告使用同一份已校验 GeoSite 的 `category-ads-all` 分类，无需另一份来源不明的数据。完整快照通过分类和当前规则验证后才原子激活。

初始化跨 Activity 重建共享一个有时限的任务，不周期轮询下载；失败保留状态并提供显式重试入口。新安装在数据就绪前不允许通过连接按钮跳过初始化。旧安装缺少数据时也执行该准备，但保留旧策略与已保存开关。已有有效快照不因每次启动重新下载，仍可手动更新。

## 默认策略

仅空白安装写入新默认值，已有加密配置、节点标识、来源、收藏、选择、规则及开关不被初始化覆盖。

- 自动优选默认开启，URL Test 为严格证书校验的 `https://1.1.1.1/`，间隔 600 秒、容差 100 毫秒。默认使用当前合并池前 16 个去重节点；导入、更新、删除来源后动态派生。少于 2 个时显示等待并使用手动节点，不进行空池探测。
- 可切换为手动候选，原有 2–16 个、间隔与容差约束继续执行；提供恢复默认配置按钮。关闭后保留关闭状态。
- 广告拦截默认开启，分类准备失败时不假装已生效；用户例外和后续关闭选择保留。
- 默认规则为局域网与国内直连、其余使用所选代理。既有用户的规则不自动换成模板。

## 路由与仪表盘

连接页显示实时概况、连接/历史入口及当前模式、优选和广告开关状态；提供规则／全局／直连切换。为避免用重连掩盖配置切换，修改须先断开，下一次连接使用新策略。全局以代理为普通流量出口，直连以 DIRECT 为普通流量出口；切换不删除原规则，切回规则模式恢复原有顺序。

手机端在三种模式下均独立保留广告拦截和代理加密 DNS；因此“直连”不代表 DNS 改走系统或取消 IPv6 保护。这一边界在界面明示，不冒充与所有 PC 配置完全相同。

规则页提供追加式局域网、局域网与国内模板；不替换既有规则。PC 常用 CSV 导入支持现有域名、IPv4 CIDR、端口、网络和 GeoIP/GeoSite 类型、`no-resolve` 及末尾 `MATCH`。`PROXY`、`节点选择`、`自动选择` 映射到手机 SELECTED；其他任意 PC 组名与进程类规则明确拒绝，不静默改成直连。MATCH 必须在最后，整份规则校验成功才保存。

## 验收

新增默认值/迁移保留、候选池随来源变化、PC CSV/MATCH 与非法导入回归；实际路由测试验证三模式的真实转发、规则恢复和运行中禁止修改。默认回归夹具显式标记已准备策略，避免被首次联网初始化干扰，不改变生产行为。

API 26 本机两项新增回归通过；通过 `MobileDefaultsTest#freshSetupDefaultsAndSavedUpgradeChoices` 加 `-e liveFirstRun true` 完成真实首次下载及地区/广告分类存在验证。实际三模式测试通过；首轮曾被系统 Google 应用崩溃弹窗阻挡，关闭弹窗后原断言通过。一次旧 UDP 快照断言跨越界面操作及网络重建，最终将原有一次 UDP 往返移到界面操作之后再检查，仍要求恰好一条有效关联、正确载荷和关闭结果，不增加应用重试。另一次本机完整运行被模拟器重启打断，未计为通过；所有失败现场保留。

新增就绪证明修复了可重复出现的快速重连误判：旧检查只凭 DNS 假地址返回即报告连接，失败现场的 HTTP 源地址实际为物理网卡 `192.168.232.2`，而新内核发包和转发载荷仍为零。新检查在原有 10 秒有界就绪流程内要求 UDP 源为 VPN 地址 `172.19.0.1`、查询事务/完整问题匹配、会话一致且本内核收发均增长；不能让外层网络的同类假 DNS 回答冒充 Android TUN 就绪。不添加固定延时或应用流量重试。新增单元回归拒绝外层源地址、旧会话、缺少发包及错误问题，7 项单元测试通过；同台模拟器的三轮快速重连及最终 20 项完整回归全部通过。本机最终原生库使用 CI 原始字节，未将不同本机库的摘要差异误当作上述故障原因。

原签名连续数据保留另在 `PrismPhoneCI` 验证：真实 Beta.3（code 4，保留此前真实 Beta.2 的夹具数据）覆盖到隔离构建的 code 5 候选，原 UID、Keystore、凭据、来源/节点标识、收藏、选择及规则通过校验；正常启动补下载缺失分类后再次校验通过。此候选使用 `de6400c` 的 Android 归档及 CI `44204505812` 的原始双架构 JNI，仅本机签署；后续配置存储代码未变化。该项使用 adb 覆盖，不宣称完成未来线上清单/下载或系统按钮安装；后加的就绪修复由完整回归另验。文件和摘要位于忽略目录 `artifacts/next-defaults-upgrade/`，未发布、未改变已有 APK。
