# 下一版启动、默认策略与路由改进（尚未发布）

本页记录 Beta.3 发布后的开发，不改变已发布 Beta.2/Beta.3 的二进制或版本号。

## 分发与兼容

主发布继续使用 `yuuolo/prism-phone` 的 Android Release；Beta.3 APK 已在该仓库。发布脚本同时保留 `yuuolo/prism` 镜像及旧仓库专用更新清单，不删除旧资产、不把旧客户端不接受的地址替换进旧通道。新旧通道使用相同原签名 APK、版本、大小与摘要，各自指向各自仓库的下载地址；桌面 latest 不参与。下一次发布必须使用大于 4 的 versionCode。

## 首次数据准备

正常首次启动自动调用生产下载器，先下载 GeoIP 和 GeoSite，核对可信发布元数据中的大小、SHA-256、来源与重定向，再生成地区/地区分类目录。广告使用同一份已校验 GeoSite 的 `category-ads-all` 分类，无需另一份来源不明的数据。完整快照通过分类和当前规则验证后才原子激活。

初始化跨 Activity 重建共享一个有时限的任务，不周期轮询下载；失败保留状态并提供显式重试入口。新安装在数据就绪前不允许通过连接按钮跳过初始化。旧安装缺少数据时也执行该准备，但保留旧策略与已保存开关。已有有效快照不因每次启动重新下载，仍可手动更新。

## 默认策略

仅空白安装写入新默认值，已有加密配置、节点标识、来源、收藏、选择、规则及开关不被初始化覆盖。

- 自动优选默认开启，URL Test 为严格证书校验的 `https://1.1.1.1/`，间隔 600 秒、容差 100 毫秒。默认使用当前合并池前 16 个去重节点；导入、更新、删除来源后动态派生。少于 2 个时显示等待并使用手动节点，不进行空池探测。
- 可切换为手动候选，原有 2–16 个、间隔与容差约束继续执行；提供恢复默认配置按钮。关闭后保留关闭状态。
- 广告拦截默认开启，分类准备失败时不假装已生效；用户例外和后续关闭选择保留。
- 默认规则为局域网与国内直连、其余使用所选代理。既有用户的规则不自动换成模板。

## 路由与仪表盘

连接页显示实时概况、连接/历史入口及当前模式、优选和广告开关状态；提供规则／全局／直连切换。为避免用重连掩盖配置切换，修改须先断开，下一次连接使用新策略。全局以代理为普通流量出口，直连以 DIRECT 为普通流量出口；切换不删除原规则，切回规则模式恢复原有顺序。

手机端在三种模式下均独立保留广告拦截和代理加密 DNS；因此“直连”不代表 DNS 改走系统或取消 IPv6 保护。这一边界在界面明示，不冒充与所有 PC 配置完全相同。

规则页提供追加式局域网、局域网与国内模板；不替换既有规则。PC 常用 CSV 导入支持现有域名、IPv4 CIDR、端口、网络和 GeoIP/GeoSite 类型、`no-resolve` 及末尾 `MATCH`。`PROXY`、`节点选择`、`自动选择` 映射到手机 SELECTED；其他任意 PC 组名与进程类规则明确拒绝，不静默改成直连。MATCH 必须在最后，整份规则校验成功才保存。

## 验收

新增默认值/迁移保留、候选池随来源变化、PC CSV/MATCH 与非法导入回归；实际路由测试验证三模式的真实转发、规则恢复和运行中禁止修改。默认回归夹具显式标记已准备策略，避免被首次联网初始化干扰，不改变生产行为。

API 26 本机两项新增回归通过；通过 `MobileDefaultsTest#freshSetupDefaultsAndSavedUpgradeChoices` 加 `-e liveFirstRun true` 完成真实首次下载及地区/广告分类存在验证。实际三模式测试通过；首轮曾被系统 Google 应用崩溃弹窗阻挡，现场日志保留，关闭弹窗后原断言通过，未放宽测试。双系统完整 CI 结果待后续记录。所有改动尚未发布，不以模拟器代替真机验收。
