## 实现顺序

1. 打通内核数据与控制：仪表盘、连接/路由详情、流量统计、DNS/网络检测、本机代理服务。
2. 建立策略配置：完整规则、自动优选、订阅合并、地区分流、广告拦截。
3. 接入链式代理并进行协议组合、断连、网络恢复与 DNS 防泄漏验证。

每一项分别记录实现、构建、模拟器验证及真机验证状态。仅新增入口、按钮、模拟数据或配置字段，不计为功能完成。

## 配置与运行要求

- 使用内嵌内核的真实数据与控制能力；应用无需开放管理 API 给外部应用。
- 完整策略配置与当前“单节点 + 直连规则”模型需要显式迁移，保留节点来源、收藏和已有设置。
- DNS 经代理、IPv6 接管和网络恢复必须随新路由及代理链一并验证，不能静默回退直连。
- 节点优选、规则更新和历史统计遵守 Android 后台与耗电约束；连接详情仅在需要时刷新。
- 安卓安装包与桌面更新通道继续独立，使用现有安卓签名覆盖更新。

## 当前交付说明

### DNS / 网络工具（未发布开发）

- 独立工具页按需发起真实 IPv4 DNS 查询与 TCP 建连检测，复用手机内核 DNS、路由、节点与 socket 保护。DNS 显示实际 A 记录（可命中内核缓存），TCP 显示真实直连/代理路径、出站链、规则及包含必要解析/代理握手的建连耗时。
- 限制输入长度、域名格式和端口，保持 IPv6 目标阻断；网络操作限时 8 秒，JNI 识别会话变化，页面暂停丢弃过期结果，恢复后可重试；不做后台持续测速。失败展示输入/会话/DNS/连接/超时阶段，不输出协议原始错误或节点凭据。
- 本地 Rust 共 9 项通过，其中新增参数、真实代理 DNS 与防 fake-IP/防直连回退、真实 TCP 直连规则测试。独立 Android 17 / 16 KiB 模拟器通过 TCP 实际代理路径、DNS 错误、IPv6/未连接拒绝及页面操作；已检查截图。
- 增加只监听主机回环、仅允许固定 DoH IP/端口的透明 SOCKS 测试中继，通过专用 ADB 端口映射连接模拟器。真实公网 DoH（保留证书校验，不替换 TLS 或 DNS 答案）与 DNS 成功页面在本地验收通过；普通失败夹具仍验证 DNS 失败不会返回 fake-IP。该成功验收依赖公网 DNS 上游可达，最多重试 3 次，不以模拟结果兜底。
- 本地 x86_64 JNI、APK、编译、单元测试与 Lint 通过；完整 CI 双架构/Release/全套模拟器验收待记录，真机未验证。

### 流量历史（未发布开发）

- 在转发计数路径增加按实际出口和命中规则类别的累计量，连接移除和网络重建不丢失；不通过低频活跃连接采样估算短连接流量。直连单列，节点使用既有节点 ID 关联显示名称；不保存目的地、规则参数、订阅地址或凭据。
- VPN 前台服务每 15 秒落盘，正常断开时等待内核停止并读取最终计数补存，空闲无新增流量不写数据库；无需额外后台作业或唤醒锁。日/月查询、实际出口/规则类别汇总和清零入口位于仪表盘。清零与服务采样串行，重新建立当前会话基线，不把清零前累计再次加回。
- SQLite 事务保存最近 400 天。日期按保存时设备本地日期计入：跨午夜最多一个采样间隔的流量可能归入新一天；系统挂起可扩大保存间隔。异常进程终止可能漏记最后未保存的增量，不保证精确到包；正常断开补存最终计数。
- 本地真实 TCP/UDP 完成及重载归属测试、SQLite 模拟器的日/月/跨会话/持久化/清零/计数回退/保留期限测试已通过；Android 编译、速率测试和 Lint 通过。另补验 DNS 隐私、fake-IP 路由与网络恢复共 5 项通过。
- [最终完整 CI 43209159973](https://github.com/yuuolo/prism-phone/actions/runs/43209159973)（`bb0b549`）的 ARM64/x86_64、Debug/Release、Lint、单元测试及模拟器 6 项全部通过。验证真实 TCP/UDP 归属、运行中清零、断开保存、跨会话保留及历史页面，并检查真实统计截图。真机未验证，未发布新 APK。

### 连接与路由详情（未发布开发）

- 从仪表盘打开独立详情页，读取真实内核连接的目的地、TCP/UDP、命中规则与参数、出站链及上下行载荷。支持目的地/规则/链搜索，网络/直连/代理筛选，按时间/流量/目的地排序；每页最多 50 条。

- 关闭操作需用户确认并携带内核会话标识，拒绝重连前的旧请求；实际取消内核 TCP/UDP 会话，应用仍可自行建立新连接。不开放外部管理 API。

### 仪表盘第一步（0.2.0-beta.2 已发布）

- JNI 状态增加内核会话标识、单调时钟运行时间、真实活跃连接数，以及启动时生效的默认节点名称和直连规则数量。不开放管理 API，不修改共享内核快照。
- 连接页在前台按秒异步采样，最多一个读取请求；切换页面、进入后台和断开时使旧结果失效。重新进入页面、新会话、累计计数回退或超过 5 秒的采样间隔均重建速率基线，不把后台累计当作瞬时速率。
- 流量口径为当前 VPN 会话内核转发的 TCP/UDP 载荷，含规则直连；不含协议开销和内核 DNS 查询。网络重建保留本会话累计，断开重连重新计数。连接数包含仍未过期的 UDP 会话。
- 保留现有加密配置、订阅来源、节点收藏、包名及升级兼容逻辑；Beta.2 的 versionCode 为 3，使用原签名并同步新旧仓库升级通道。历史统计尚未实现，因此不增加不可用的历史入口，本项仍未达到完整版验收目标。
