## 稳定版剩余验收

当前功能已进入完整软件回归阶段，已发布包仍为 Beta.2。以下不能用模拟器或隔离协议夹具代替，未通过前不宣称稳定版：

| 验收项 | 当前证据与剩余条件 |
| --- | --- |
| 原签名覆盖 | 双模拟器真实 Beta.2 覆盖与 Keystore/配置保留通过；仍需 ARM64 真机覆盖及正常内置高版本更新流程 |
| 实际节点 | 六类基础协议有代表性握手/载荷/UDP 组合、严格证书拒绝与真实公网 DoH；仍需使用实际服务端账号核对 TLS、UDP 能力和断连行为 |
| 后台与耗电 | 双系统短时熄屏及独立 180 秒 Doze、冷 DNS/TUN/TLS、恢复和断开对照通过；仍需真机长时锁屏、省电、后台与资源/耗电观察 |
| 网络与隐私 | 已验证内核重建、模拟器 OS Wi-Fi/蜂窝往返、出口/计数保留、链中断不直连、IPv6 拒绝；仍需真机无线/飞行模式切换及双栈网络观察 |
| 局域网共享 | 模拟器 TCP/UDP、授权和停止释放通过；仍需另一台设备入站、热点、拒权/撤权及厂商系统行为 |

用户当前无可用真机，继续软件验收并保留这些缺口；不为消除 Beta 标识而省略验收。iOS 与 HarmonyOS NEXT 继续暂停。

## 实现顺序

1. 打通内核数据与控制：仪表盘、连接/路由详情、流量统计、DNS/网络检测、本机代理服务。
2. 建立策略配置：完整规则、自动优选、订阅合并、地区分流、广告拦截。
3. 接入链式代理并进行协议组合、断连、网络恢复与 DNS 防泄漏验证。

每一项分别记录实现、构建、模拟器验证及真机验证状态。仅新增入口、按钮、模拟数据或配置字段，不计为功能完成。

## 配置与运行要求

- 使用内嵌内核的真实数据与控制能力；应用无需开放管理 API 给外部应用。
- 完整策略配置与当前“单节点 + 直连规则”模型需要显式迁移，保留节点来源、收藏和已有设置。
- DNS 经代理、IPv6 接管和网络恢复必须随新路由及代理链一并验证，不能静默回退直连。
- 节点优选、规则更新和历史统计遵守 Android 后台与耗电约束；连接详情仅在需要时刷新。
- 安卓安装包与桌面更新通道继续独立，使用现有安卓签名覆盖更新。

### 系统网络恢复修复（未发布开发）

- 修正原生恢复限频丢弃末次事件的问题：原实现忽略距上次重建不足 3 秒的事件，窗口内最后一次变化后可能不再重建。现在首个事件立即处理，窗口内事件合并后仍会执行，重建开始间隔至少 3 秒。通道只保留一个待处理信号，合并也只有一次非阻塞读取；空闲时没有轮询或额外任务，停止取消等待，重连创建独立通道。
- 除网络出现/消失外，监听物理地址、路由、DNS、验证和挂起状态变化，以及系统向 VPN 公布的底层默认传输变化；API 29 起还比较 MTU。快照只驻留内存，不记录地址或 DNS 历史，不自行选择网络。回调统一在主 handler 处理，检查服务实例和会话 generation，断开时注销两类回调，拒绝旧服务的迟到通知。
- 内部状态 `networkRebuilds` 只累计本会话真实成功重建，用于验收定位，不开放管理 API。重建保留 VPN fd、fake-IP、规则、当前优选、链路及统计；优选重建后的探测节流保持不变。
- Rust 32 项和 Android 6 项单元测试通过，新增虚拟时间的窗口末尾/有界风暴/停止重连，以及能力、DNS/地址和默认传输变化测试。Debug/Release 构建和双 Lint 通过，本地 API 26 与 Android 17 各 18 项完整回归通过。
- 新增真实 OS 切换验收：从虚拟 Wi-Fi 切到蜂窝再返回 Wi-Fi，核对系统实际默认网络和成功重建计数；不在切换阶段直接调用 JNI 重建。新载荷发送前即验证累计流量未清零，再验证原会话、两跳公网 DoH、经本机代理的真实 TLS 载荷及末跳流量归属。首跳经来宾系统物理路由到宿主回环夹具（19092），只转固定第二跳（19090），第二跳只到 `1.1.1.1:443`，不使用 adb reverse、TLS 解密或替换 DNS 答案，两个监听器和工作队列有界。
- API 26 镜像 shell 无 Wi-Fi 切换权限，测试改用 Debug 专属普通 Wi-Fi 权限调用系统 API；无需 root，不改变正式权限。CI 新增 Release 包名和无测试 Wi-Fi 权限的检查。API 26 不向 VPN 公布底层传输标签，验收读取模拟器系统实际默认网络，而非假设新 API 行为；测试结束恢复原 Wi-Fi 状态，不更改移动数据设置。

### 广告域名拦截（未发布开发）

- 连接页在前台按秒异步采样，最多一个读取请求；切换页面、进入后台和断开时使旧结果失效。重新进入页面、新会话、累计计数回退或超过 5 秒的采样间隔均重建速率基线，不把后台累计当作瞬时速率。
- 流量口径为当前 VPN 会话内核转发的 TCP/UDP 载荷，含规则直连；不含协议开销和内核 DNS 查询。网络重建保留本会话累计，断开重连重新计数。连接数包含仍未过期的 UDP 会话。
- 保留现有加密配置、订阅来源、节点收藏、包名及升级兼容逻辑；Beta.2 的 versionCode 为 3，使用原签名并同步新旧仓库升级通道。历史统计尚未实现，因此不增加不可用的历史入口，本项仍未达到完整版验收目标。
- 验证状态见下方记录；本版已通过完整 CI 与模拟器，尚未通过真机验收。
