## 实现顺序

1. 打通内核数据与控制：仪表盘、连接/路由详情、流量统计、DNS/网络检测、本机代理服务。
2. 建立策略配置：完整规则、自动优选、订阅合并、地区分流、广告拦截。
3. 接入链式代理并进行协议组合、断连、网络恢复与 DNS 防泄漏验证。

每一项分别记录实现、构建、模拟器验证及真机验证状态。仅新增入口、按钮、模拟数据或配置字段，不计为功能完成。

## 配置与运行要求

- 使用内嵌内核的真实数据与控制能力；应用无需开放管理 API 给外部应用。
- 完整策略配置与当前“单节点 + 直连规则”模型需要显式迁移，保留节点来源、收藏和已有设置。
- DNS 经代理、IPv6 接管和网络恢复必须随新路由及代理链一并验证，不能静默回退直连。
- 节点优选、规则更新和历史统计遵守 Android 后台与耗电约束；连接详情仅在需要时刷新。
- 安卓安装包与桌面更新通道继续独立，使用现有安卓签名覆盖更新。

### GeoIP / GeoSite 地区分流（未发布开发）

- 显式从 [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat) 的 GitHub 发布下载完整 `geoip.dat` / `geosite.dat`；验证同一次发布元数据的大小和 SHA-256。仅 HTTPS 和固定 GitHub 官方主机，不发送账号凭据；每文件最多 32 MiB，下载约束 4 分钟，单任务，无定时后台更新。
- 两个数据文件写入独立快照并检验分类后，以加密配置事务切换指针；失败保留旧指针，成功保留当前和上一快照，清理只涉及已知数据文件。页面展示上游版本、发布时间、本机安装时间、摘要及可搜索/分页的分类；数据不随 APK 捆绑，源文件和分类由上游维护。
- 路由规则增加 GEOSITE / GEOIP，沿用用户规则组和规则顺序首次命中、启停、直连/拒绝/所选节点与默认出口。各最多启用 8 个分类；GeoIP 可 no-resolve，触发解析时仍走内核代理 DNS。保存规则时异步校验数据和分类，避免文件/解析工作阻塞页面；地区分类不等同设备实际位置，IPv6 目标仍阻断。
- 启用地区规则前必须有完整快照；启动逐文件验证摘要并验证所有启用分类非空，缺失、损坏或未知分类明确失败，防止内核跳过规则后放行。网络重建再次验证摘要，失败时保留已加载规则并暂停重建，仪表盘提示断开后更新；不丢弃现有规则。
- 本地 Rust 19 项与共享内核 DNS/fake-IP/流量/恢复 6 项通过，Android 编译/Lint 和模拟器十三项完整回归通过。确定性 protobuf 夹具验证真实 GeoSite 拒绝、GeoIP 直连、例外优先、默认出口、损坏恢复保留规则及拒绝重新启动。另在隔离模拟器通过生产下载器从上游真实下载、摘要/分类验证及实际 CN 域名/IP 命中；CI 默认使用确定性夹具，上游真实下载通过 `liveGeodata=true` 单独验收，未把夹具当作真实地区数据。双架构 CI 与真机验收待记录，未发布 APK。

### 自动优选（未发布开发）

- 默认关闭，显式选择 2–16 个现有节点，间隔 300–3600 秒（默认 600）、容差 0–2000 毫秒（默认 100）。配置加密保存且仅断开时修改；候选来自已有来源，不复制或改写订阅、收藏与手动选择。来源更新移除候选后明确拒绝启动，需重新配置。
- 使用内核 url-test 组，通过候选各自真实 HTTPS/TLS 通道比较握手/响应起始耗时，固定目标 `https://1.1.1.1/`，保留证书校验。每候选限时 5 秒，每轮至多 16 次；启动约 1 秒后首轮，首轮前使用第一个候选。当前失败或其他节点快于容差时切换，新连接使用新出口，已有连接不强制迁移；全部失败保留候选，连接可失败但不静默直连。
- 网络重建保留上次选择，清空旧探测结果并延后 300 秒再测，频繁重建不会每次立即探测；普通周期按设定间隔运行。VPN 断开销毁健康检查任务，页面只在前台读取状态，不发起额外探测。
- 页面显示实际出口、逐候选耗时/失败/未探测及时间；仪表盘和 DoH 诊断显示实际选择，转发流量仍按真实候选节点 ID 归属历史，探测流量不计转发历史。局域网权限检查覆盖全部候选，本机代理端口检查覆盖全部回环候选。
- 本地 Rust 18 项及共享内核流量/DNS/fake-IP/恢复共 6 项通过，新增真实 SOCKS/HTTP 健康检查验证容差、失败回退、全部失败不直连、网络重建保留和节流。独立 Android 17 / 16 KiB 模拟器最终十一项完整回归及编译/Lint 通过，含真实 TLS 选出可用候选、随后真实 DoH、应用 TLS 载荷按候选 ID 归属，以及真实网络重建后出口保留和延后探测，已检查结果页面。[完整 CI 43257961173](https://github.com/yuuolo/prism-phone/actions/runs/43257961173)（`3d562e7`）双架构、Debug/Release、Lint、单元测试及模拟器十一项全部通过；修正了旧截图测试切页后使用失效滚动控件的竞态。真机仍未验证，未发布 APK。

### 本机代理服务（未发布开发）

- 显式启动 HTTP / SOCKS5 TCP / SOCKS5 UDP 共用 IPv4 端口，默认仅监听回环；允许自动分配或指定 1024–65535。配置导入、启动应用与连接 VPN 均不自动开启。实际地址、端口和范围来自原生监听状态；沿用 VPN 的真实规则、节点与流量统计。
- 局域网共享需要单独选择、Android 17 授权及每次启动确认，监听所有 IPv4 接口，仅接受回环、私网或链路本地来源，无额外客户端认证。前台通知显示共享状态；真机局域网入站、热点和厂商后台行为仍待验证。
- TCP/UDP 绑定失败整体回滚；限制并发 TCP 客户端 256、UDP 目标会话 128 及每会话队列 16。SOCKS UDP 必须有存活控制连接，控制连接关闭即取消关联会话。停止服务取消已有转发并释放端口，VPN 保持运行；VPN 断开停止所有代理任务。
- Android 监听 socket 受 VPN 保护，接入连接复用原生路由；拒绝过期会话、IPv6 目标及与所选回环节点相同端口的自环。JNI 不开放管理端口，日志不输出节点凭据。
- 本地 Rust 13 项及共享内核流量/DNS/fake-IP/网络恢复共 6 项通过；独立 Android 17 / 16 KiB 模拟器九项完整回归通过，含真实 HTTP、SOCKS TCP/UDP、未关联 UDP 丢弃、停止长连接、端口释放、VPN 继续转发、共享确认取消、回环隔离及设备私网地址共享，已检查截图。[完整 CI 43228146458](https://github.com/yuuolo/prism-phone/actions/runs/43228146458)（`41a2c27`）双架构、Debug/Release、Lint、单元测试及模拟器全部通过；尚未发布 APK。

### 流量历史（未发布开发）
