# Prism Android 0.2.0-beta.3

本次交付完整功能范围的 Android Beta，尚非稳定版。已有 Beta 用户可沿用原签名覆盖升级，保留加密配置、节点来源、收藏与选择；升级前请保留自己的订阅地址。

- 仪表盘与连接：真实速率、运行状态、连接详情、搜索/筛选/排序和关闭连接；增加跨会话日/月、实际出口与规则类别流量统计。
- 网络工具与共享：真实 DNS、TCP 路径及耗时检测，显式启停的 HTTP/SOCKS5 TCP/UDP 本机代理与局域网共享，Android 17 局域网授权。
- 路由策略：有序规则组、编辑/导入/启停、直连/拒绝/所选节点与默认出口；地区 GeoIP/GeoSite 下载及完整性校验。
- 广告拦截：分类、用户例外、启停及实际拒绝计数。
- 节点策略：受限候选的真实 TLS 自动优选、容差与失败切换；多来源订阅合并、去重及同名区分；固定 2–4 跳链式代理、能力/循环校验及代理 DNS。
- 稳定性：修复 DNS 连接池失效恢复、网络变化末次事件遗漏与旧注册表引用环；保留路由、DNS 隐私及用户断开后不自动重连的约束。
- 升级：坏下载缓存可恢复重新下载；Android 17 支持系统按次来源授权，打开安卓发布页指向手机独立仓库。旧仓库兼容更新通道继续维护。

软件验收覆盖 ARM64/x86_64、Debug/Release、双 Lint、Rust/Android 单元测试，以及 API 26 和 Android 17/16 KiB 模拟器各 18 项完整回归与各自独立 180 秒 Doze。原证书高版本升级已验证 UID、Keystore 与配置保留，真实 Beta.1→Beta.2 线上检查/下载及旧通道兼容通过；各阶段证据边界见仓库验收文档。
