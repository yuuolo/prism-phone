# Prism Android 0.2.0-beta.5

本次是高级能力扩展的第一批 Beta 更新，主要完善现有候选组；不是七项扩展目标已经全部完成。沿用原包名和签名，保留旧配置与兼容更新通道。

- 候选组新增自动优选（url-test）、故障转移（fallback）和按目标主机保持粘性的负载均衡。fallback 使用首个可用候选；均衡不冒称唯一出口，连接和统计仍归属实际使用的节点。
- 支持自定义 HTTPS 检测地址。默认仍为 `https://1.1.1.1/`、600 秒间隔、100 毫秒容差；旧配置缺少新字段时沿用原行为，不改写已有候选和开关。容差只影响 url-test。
- 保留最多 16 个候选、5 秒单次超时、断开即停止及全部失败不回退直连。检测地址初期不接收账号、查询参数、片段、零端口或 IPv6 目标。
- 网络重建延后重测时，保留相同策略/检测地址下未变化节点的已知可用性，避免重新选择已失败成员；不伪造延迟值或探测时间，节点参数变化不继承旧状态。

新增真实 fallback 载荷、均衡分配/粘性、全部失败不直连、连续重建和节点变化回归；Android 验证两种策略的真实 TLS、实际出口流量归属及重建后的代理 DNS。

后续仍在开发：高级协议与传输的 Android 开放、完整 Clash/sing-box 配置与 providers、JavaScript 配置覆写、自定义多组/规则集/按应用分流、运行中热重载、完整 DNS/IPv6、应用流量/地图/质量曲线。当前未通过验收的能力仍明确拒绝，路线见 `docs/android-advanced.md`。

主发布在 prism-phone，旧仓库继续提供兼容镜像及更新清单。真机长时后台、耗电、无线/双栈、第二设备共享与实际账号仍待验证；iOS 和 HarmonyOS NEXT 继续暂停。
