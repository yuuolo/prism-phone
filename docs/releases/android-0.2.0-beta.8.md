# Prism Android 0.2.0-beta.8

高级扩展第三批：可配置的加密 DNS、分域策略、fallback 与静态 hosts。延续 Beta.7 的按应用 VPN 分流、候选策略和真实质量曲线。新增七项高级目标仍未全部完成。

- “设置 → DNS 高级设置”配置普通 DNS（1–3 个）、节点域名引导 DNS（1–2 个）、按域名选择上游（16 条，每条最多 2 个）、fallback（3 个）与其域名/结果网段（各 32 条），以及精确域名 hosts（128 条）。支持 HTTPS DoH 和 TLS DoT，保留严格证书校验；不接收明文协议、认证信息、查询参数或自定义代理片段。配置总量不超过 64 KiB，保存需先断开，下次连接生效；旧版本保持原 DNS 默认，不改写原配置。
- 普通 DNS、分域策略和 fallback 始终经当前代理或固定代理链，不静默改用系统 DNS、节点引导 DNS或直连。节点引导上游独立使用加密公网 IPv4 字面地址，避免递归。分域策略按顺序首次命中，不再使用普通/fallback 上游。
- fallback 沿用内核语义：同时请求主/候补，主结果为空或命中所设 IPv4 网段时采用候补，指定域名可只使用候补；候补失败仍可能采用主结果。不会因失败改成直连。本批不启用隐式 GeoIP 过滤。
- hosts 保留客户端 fake-IP 和域名选路，规则匹配后再使用绑定的 IPv4 进行 TCP/UDP 拨号；代理规则仍走代理，域名拒绝与广告拦截不会因 hosts 丢失域名而被绕过。节点域名 hosts 的局域网覆盖也纳入权限预检。不接受 IPv6、未指定/广播/组播、fake-IP 或 VPN 内部地址。没有覆盖的域名仍按 DNS 策略处理。

绕过 VPN 的应用使用系统网络，不进入此 DNS 配置。hosts 作用于内核解析及规则选路的连接，不承诺远端代理服务器自己的其他 DNS 行为。IPv6、完整 Clash/sing-box 配置与 providers、JavaScript 覆写、多自定义组、热重载、其他高级协议、应用统计/地图仍在开发。

沿用原包名、签名、加密配置和兼容更新通道；主发布为 prism-phone，旧仓库继续同包镜像，不修改桌面 latest。iOS 和 HarmonyOS NEXT 暂停。真机长时后台、耗电、无线与双栈、第二设备及实际账号仍待验证，继续保持 Beta。
