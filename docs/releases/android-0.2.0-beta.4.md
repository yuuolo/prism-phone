# Prism Android 0.2.0-beta.4

Android Beta 更新，尚非稳定版。沿用原包名及签名，支持既有 Beta 覆盖升级，保留加密配置、Keystore、节点来源、收藏、选择和已有开关。

- 首次启动自动补齐并校验 GeoIP、GeoSite、地区分类和广告分类；缺少数据的旧安装也会初始化。已有有效快照保留，失败可显式重试，不跳过完整性校验。
- 新安装默认开启自动优选与广告拦截，默认局域网和国内直连、其余使用代理；已有用户的规则与开关不被新默认值覆盖。
- URL Test 默认严格校验证书的 `https://1.1.1.1/`，间隔 600 秒、切换容差 100 毫秒。默认候选随当前合并池派生，最多 16 个；不足 2 个时等待并保留手动节点，可改为手动候选或恢复默认配置。
- 仪表盘增加清晰的路由模式、优选和广告状态；提供规则／全局／直连三模式，切换须先断开，切回规则模式保留原规则。三种模式均独立保留广告拦截和代理加密 DNS，直连不表示 DNS 改走系统。
- 路由页增加追加式常用模板、PC 常用 CSV 与末尾 MATCH 导入；PROXY、节点选择、自动选择映射到手机策略。无法映射的组和不支持的进程规则明确拒绝，不静默改成直连。
- 修复快速重连过早报告“已连接”：就绪检查同时验证 VPN 源地址、本次 DNS 问题、本会话及内核实际收发，避免外层网络的假 DNS 回答冒充 Android TUN 就绪。不添加固定延时或应用流量重试。

主发布在 `yuuolo/prism-phone`，旧仓库继续镜像同一 APK 并维护兼容更新清单；不删除 Beta.2/Beta.3 资产，不改变桌面更新通道。Android 17 的旧 Beta.2 若反复打开来源设置，可从发布页下载后通过系统文件管理器覆盖安装。

发布须通过双架构 Debug/Release、双 Lint、32 项手机 Rust、101 项共享内核回归、7 项 Android 单元测试，以及 API 26 与 Android 17/16 KiB 各 20 项回归和各自独立 180 秒 Doze。首次真实数据下载、默认值及原证书高版本配置保留已有独立验收，证据边界见仓库文档。
