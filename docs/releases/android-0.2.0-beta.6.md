# Prism Android 0.2.0-beta.6

高级扩展第二批：按应用控制 VPN 接管范围，以及真实候选节点质量历史。七项高级目标尚未全部完成，仍为 Beta；iOS 和 HarmonyOS NEXT 暂停。

- 新增按应用分流：全部应用、仅所选应用经过 VPN、所选应用绕过 VPN。进入 VPN 的应用继续遵循规则/全局/直连模式；绕过的应用使用系统网络，不进入 Prism 广告拦截、DNS 与流量统计。Prism 自身保留在 VPN 内以支持状态和网络检测。这不是为每个应用指定不同代理组。
- 支持搜索当前可见启动器应用、手动添加可见的已安装包名、查看/删除失效选择；最多 256 个包名，不申请 QUERY_ALL_PACKAGES。Android 按 UID 生效，共用 UID 的应用会一同生效；工作资料/其他用户受各自 VPN 策略约束。所选应用被卸载或不可见时拒绝启动，不静默扩大接管范围。修改需断开，下次连接生效；旧配置默认保持全部应用。
- 新增节点质量曲线：读取当前候选组已有的最近 10 次真实 HTTPS 探测，显示时间、耗时、最小/平均/最大和失败次数。失败单独标记并断开曲线，不伪装 0 ms 或网络丢包率；页面不触发测速，前台每 2 秒读取，离开停止读取。断开或网络重建后清空，未探测节点明确显示暂无数据。

按应用设置控制系统 VPN 路由。应用主动使用本机 HTTP/SOCKS5 代理时仍会通过该代理；系统“阻止无 VPN 连接”等策略也可能限制绕过应用的网络。完整配置、JavaScript 覆写、providers、多自定义组、按应用指定代理、热重载、高级协议、DNS/IPv6 与应用统计/地图仍按 `docs/android-advanced.md` 继续开发，不将界面或内核代码当作已验收交付。

沿用原包名、签名与加密配置。主发布在 yuuolo/prism-phone，旧仓库保留同包镜像及独立兼容更新地址；不会改变桌面 latest。真机长时后台、耗电、无线与双栈切换、第二设备共享及实际账号仍待验收。
