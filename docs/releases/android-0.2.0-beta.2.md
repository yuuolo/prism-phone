# Prism Android 0.2.0-beta.2

本次为 Android Beta 更新，尚未达到手机版完整版或稳定版验收标准。

- 连接页新增真实内核运行时间、实时上下行速率、活跃连接数、规则策略和默认出口节点。
- 统计读取移出界面线程；离开连接页、进入后台或断开时停止采样并丢弃过期结果。重连和长时间暂停后重新建立速率基线。
- 流量累计仅包含当前 VPN 会话的 TCP/UDP 转发载荷（含规则直连），不含协议开销和内核 DNS 查询。UDP 连接数包含尚未过期的会话；日/月历史统计尚未实现。
- 保留既有加密配置、节点来源、收藏和设置。沿用 `dev.prism.android` 包名与原安卓签名，可从 Beta.1 覆盖升级；Alpha.1 用户仍需手动下载安装一次。
- 手机端独立仓库发布，同时在原仓库镜像同一签名 APK，并维护 Beta.1 兼容升级清单。桌面更新通道保持独立。

发布门槛为 Android CI 的 Rust 策略测试、速率单元测试、ARM64/x86_64 原生库、Debug/Release 构建、Lint 和 Android 17 / 16 KiB 页模拟器验收通过；发布流程只在这些任务全部成功后签名上传。

真机的 Wi-Fi/蜂窝切换、锁屏、后台、耗电和覆盖升级仍待验证。iOS/iPadOS 与 HarmonyOS NEXT 继续暂停。
