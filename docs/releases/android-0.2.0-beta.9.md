# Android 0.2.0-beta.9 发布候选

本候选优先修复连接与切网恢复，尚未发布，不包含正在开发的 VMess。

- 网络重建后 2 秒发起候选健康检查，替换此前的 300 秒等待；不保证 2 秒完成恢复，常规间隔及保存的用户选择保持不变。

发布前还须完成本候选 CI、原签名 APK 校验与覆盖升级验收。当前没有真机长时、耗电或实际无线网络验收，不将此候选宣称为稳定版。
